# si-9951-exemplos — Sistemas de Informação (12ºMM)

Exemplos do professor da UFCD 9951 Linguagem de programação web de servidor, mostrados nas aulas. É público: qualquer aluno pode consultar e clonar.

## Como está organizado

```
si-9951-exemplos/
  README.md          este ficheiro
  aula-01/           uma pasta por aula, com os ficheiros dessa aula
    diagnostico.html
    css/
      estilo.css
  aula-03/
    ola.php
```

A estrutura é a mesma que se pede no repositório de cada aluno: uma pasta `aula-NN` por aula, com os ficheiros dentro e as folhas de estilo em `css/`, sempre com dois algarismos, sem espaços, sem acentos e em minúsculas.

## Como usar

```
git clone https://github.com/joaofonsecasynget/si-9951-exemplos.git
```

Clona-o dentro da pasta `htdocs` do XAMPP, para as páginas correrem no servidor local. Antes de cada aula, faz `git pull`.

Copiar daqui para o teu repositório é permitido e recomendado: o que conta é perceberes o código e conseguires explicá-lo.
